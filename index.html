Recovery Guarantee

PATCHVAULT never runs git reset --hard or stages/commits your files. Recovery inspects current SHA-256 hashes against original snapshot blobs. If any external conflict is detected, recovery halts without touching any file.

Division of Responsibility & Architecture

Engineered specifically for autonomous coding workflows with TrueFoundry's TrueForge agent harness.

TrueForge (Agent Harness)
Owns the agent loop, model calls, tool execution, session state, and streaming. PATCHVAULT never implements its own LLM loop.
PATCHVAULT (Flight Recorder)
Owns checkpoints, Change Capsules, workspace change detection, unified LCS diffing, hunk-level approval, and safe rollback.
Content-Addressed Blobs
Pre-task file content is stored in atomic SHA-256 blob stores. Tampered or missing blobs are instantly detected and flagged.
Hunk-Level Granularity
Accept good changes while safely rejecting and reverting bad hunks in the same file with zero collateral damage.
Native SecretStorage
TrueForge API keys and credentials reside in the OS Keychain via VS Code SecretStorage, never in settings or logs.
No Fake Percentages
Confidence states (Protected, Needs Review, Verification Failed, Recovery Available) are 100% fact-driven rule outcomes.
